# 프롬프트 서가 · 수업별 자료실

## 공유 주소

- 전체 수업 목록: https://apple115-code.github.io/prompt/
- 기존 가상현실 수업: https://apple115-code.github.io/prompt/?course=vr
- 선생님 편집: https://apple115-code.github.io/prompt/teacher.html

선생님 화면에서 수업을 선택하고 ‘수강생 공유 주소 복사’를 누르면 해당 수업만 여는 주소가 복사됩니다. 수업 이름을 바꿔도 주소는 유지됩니다. 수업을 삭제하면 기존 주소에는 찾을 수 없다는 안내가 나옵니다. 공개 자료실이므로 주소 분리는 접근 권한을 제한하는 기능이 아닙니다.

## 새 수업 만들기

1. 선생님 편집 주소를 엽니다.
2. ‘+ 수업 추가’를 누르고 이름을 입력합니다.
3. 수업 제목·소개와 카테고리 이름을 편집합니다.
4. ‘+ 새 프롬프트’를 누르고 제목과 본문을 작성합니다.
5. ‘변경 내용 저장’을 누릅니다.
6. GitHub 로그인 후 ‘수강생에게 게시’를 누릅니다.
7. 게시 완료가 표시되면 해당 수업 주소를 공유합니다.

저장은 브라우저 초안에 적용되며, 게시는 저장된 전체 수업을 함께 갱신합니다. 입력 중인 내용이 있으면 먼저 저장해야 합니다. GitHub 파일을 직접 교체할 필요가 없습니다. 페이지 새로고침 시 GitHub에 다시 로그인합니다.

## 복제·삭제·카테고리

- 수업 복제: 수업의 카테고리와 프롬프트를 복사합니다. 원래 수업은 유지하고 새 공유 주소를 만듭니다.
- 수업 삭제: 확인 후 해당 수업과 모든 프롬프트를 브라우저 초안에서 제거합니다. 게시해야 수강생에게 반영됩니다.
- 프롬프트 삭제: 선택한 항목만 삭제합니다.
- 카테고리 이름 변경: 수업마다 자유롭게 바꿉니다. 다른 수업에는 영향을 주지 않습니다.
- 사용 중인 카테고리 삭제: 먼저 프롬프트를 다른 카테고리로 옮겨 저장한 뒤 삭제합니다.

## 백업

‘전체 수업 백업 다운로드’로 JSON 파일을 보관합니다. ‘백업 불러오기’는 현재 브라우저의 모든 수업을 교체하므로 확인 후 진행합니다. 실제 게시 전까지 수강생 화면은 유지됩니다. 처음 전환 전의 prompts.js 및 기존 브라우저 저장 키도 삭제하지 않았습니다.

## 수강생 화면

수업별 검색·카테고리·접이식 카드·전체 복사를 지원합니다. 최신 데이터는 캐시를 피해서 읽으며 열어 둔 화면도 30초마다 확인합니다. ‘최신 내용 확인’으로 바로 갱신할 수도 있습니다. 수강생 화면에는 편집 기능이 없습니다.

## 구조

수업과 프롬프트는 library.json 하나에 함께 저장됩니다. course-boot.js가 최신 자료를 불러오고, course-app.js가 수업별 화면을 표시하며, course-editor.js가 초안을 관리합니다. publisher.js는 Cloudflare 인증 서버의 /api/v2 경로로 GitHub 로그인·게시를 처리합니다. 서버는 apple115-code/prompt의 library.json만 수정합니다. 기존 편집 화면의 오래된 게시 요청은 덮어쓰기를 방지하기 위해 거부합니다.

GitHub Pages 설정은 GitHub Actions이며 .github/workflows/publish.yml이 JSON 변경도 자동 배포합니다. 수강생은 로그인 없이 사용합니다. 게시 충돌이 나면 초안을 백업하고 최신 자료를 불러와 비교하세요. 비밀 키와 GitHub 원본 토큰을 공개 파일에 넣지 마세요.

로컬 파일은 압축을 푼 뒤 index.html 또는 teacher.html을 열 수 있습니다. 이때 library-data.js에 포함된 배포 시점 자료를 사용합니다. 최신 온라인 자료와 자동 동기화되지는 않습니다. 실제 게시는 HTTPS 편집 주소를 이용하세요.
