# 프롬프트 서가 · 수업별 자료실

## 공유 주소

- 수강생: https://apple115-code.github.io/prompt/
- 선생님: https://apple115-code.github.io/prompt/teacher.html

편집할 수업을 선택하고 ‘이 수업을 수강생에게 표시’를 누른 다음 ‘수강생에게 게시’를 누르세요. 수강생은 같은 주소에서 지정된 수업만 봅니다. 수강생 화면에는 수업 선택 목록이 없습니다. 편집할 수업을 선택하기만 해서는 표시 수업이 바뀌지 않습니다.

## 새 수업 만들기

1. 선생님 편집 주소를 엽니다.
2. ‘+ 수업 추가’를 누르고 이름을 입력합니다.
3. 수업 제목·소개와 카테고리 이름을 편집합니다.
4. ‘+ 새 프롬프트’를 누르고 제목과 본문을 작성합니다.
5. ‘변경 내용 저장’을 누릅니다.
6. ‘이 수업을 수강생에게 표시’를 누르고 GitHub 로그인 후 ‘수강생에게 게시’를 누릅니다.
7. 게시 완료가 표시되면 수강생 주소를 공유합니다.

저장은 브라우저 초안에 적용되며, 게시는 저장된 전체 수업을 함께 갱신합니다. 입력 중인 내용이 있으면 먼저 저장해야 합니다. 프롬프트와 표시 수업은 Cloudflare에 직접 저장되어 GitHub Pages 배포를 기다리지 않습니다. GitHub 파일을 직접 교체할 필요가 없습니다. 페이지 새로고침 시 GitHub에 다시 로그인합니다.

## 복제·삭제·카테고리

- 수업 복제: 수업의 카테고리와 프롬프트를 복사합니다. 원래 수업은 유지됩니다. 표시할 수업을 지정하고 게시해야 수강생 화면이 바뀝니다.
- 수업 삭제: 확인 후 해당 수업과 모든 프롬프트를 브라우저 초안에서 제거합니다. 게시해야 수강생에게 반영됩니다.
- 프롬프트 삭제: 선택한 항목만 삭제합니다.
- 카테고리 이름 변경: 수업마다 자유롭게 바꿉니다. 다른 수업에는 영향을 주지 않습니다.
- 사용 중인 카테고리 삭제: 먼저 프롬프트를 다른 카테고리로 옮겨 저장한 뒤 삭제합니다.

## 백업

‘전체 수업 백업 다운로드’로 JSON 파일을 보관합니다. ‘백업 불러오기’는 현재 브라우저의 모든 수업을 교체하므로 확인 후 진행합니다. 실제 게시 전까지 수강생 화면은 유지됩니다. 처음 전환 전의 prompts.js 및 기존 브라우저 저장 키도 삭제하지 않았습니다.

## 수강생 화면

수업별 검색·카테고리·접이식 카드·전체 복사를 지원합니다. 최신 데이터는 캐시를 피해서 읽으며 열어 둔 화면도 5초마다 확인합니다. ‘최신 내용 확인’으로 바로 갱신할 수도 있습니다. 수강생 화면에는 편집 기능이 없습니다.

## 구조

화면은 GitHub Pages에서 제공하고, 최신 수업은 Cloudflare Worker의 /api/v3/library에서 불러옵니다. 선생님의 GitHub 로그인은 유지하되 게시 내용은 SQLite 기반 Durable Object에 저장합니다. 게시 성공 응답 이후 읽기는 새 게시본을 반환합니다. 표시 수업은 courses의 첫 항목입니다.

같은 버전을 기반으로 동시에 게시하면 먼저 성공한 게시만 반영하고 다른 요청은 충돌 안내를 표시합니다. 저장소에는 현재 게시본과 직전 게시본을 보관합니다. 전체 수업 백업 다운로드로 별도 백업을 보관하세요. library.json은 이전 GitHub 게시 시점의 자료로, 이제 실시간 원본이 아닙니다.

화면 디자인과 기능을 바꿀 때만 GitHub Pages를 배포합니다. 기존 주소는 유지됩니다. 수강생은 로그인 없이 사용합니다. 공개 자료실이므로 수업 선택 숨김은 비공개 접근 제어 기능이 아닙니다.

로컬 파일을 열면 library-data.js에 포함된 배포 시점 자료를 사용합니다. 실제 최신 내용과 게시는 HTTPS 편집 주소를 이용하세요.
